# Student Scores Analysis

## Overview

This project analyzes student performance data using Python.
It demonstrates how to generate synthetic data, perform statistical analysis, and extract meaningful insights from student scores.

The analysis is implemented in a Jupyter Notebook:
student_scores_analysis.ipynb

---

## Objectives

* Generate synthetic dataset (20 students × 5 subjects)
* Perform overall statistical analysis (mean, max, min, standard deviation)
* Identify the hardest subject based on average scores
* Calculate student-wise averages
* Detect struggling students (average < 75)
* Extract top 5 performing students
* Add a new student to the dataset
* Remove the lowest-performing student
* Generate a final performance report with insights
